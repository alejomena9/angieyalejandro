# Fotos para el álbum Nuestros Recuerdos

Cada carpeta dentro de `fotos/` es un recuerdo del álbum.

## Cómo nombrar cada carpeta

`AAAA-MM-DD-titulo-del-recuerdo`

Ejemplos:

- `2025-02-14-primera-cita`
- `2025-06-21-viaje-a-cartagena`
- `2025-12-24-navidad-con-la-familia`

La fecha va primero y el título después, con guiones en lugar de espacios.

## Qué va dentro

- Fotos: `.jpg`, `.jpeg`, `.png`, `.heic`, `.webp`
- Videos: `.mp4` o `.mov`, de máximo 20 MB cada uno

## Opcional: lugar y nota

Si quieres agregar el lugar o lo que pasó ese día, crea dentro de la carpeta un archivo `info.txt` así:

```
lugar: Cartagena, Colombia
nota: El día que vimos el atardecer en la muralla.
```

## Cómo subir desde GitHub

1. Abre la carpeta `fotos/` en github.com.
2. Toca **Add file → Upload files**.
3. Para crear una carpeta nueva, arrastra la carpeta completa desde tu computador, o escribe el nombre de la carpeta seguido de `/` antes de subir los archivos.
4. Dale a **Commit changes**.

Cuando termines, avísale a Claude para que pase todo al álbum.
